Fleet refresh

Refresh settings

These limits control background status checks and direct updates on the Update Workbench. Each automatic update refresh checks the official plugin catalogues again.

Direct updates default to five different websites at once. A single website is always updated one item at a time. Use fewer parallel operations for slower hosting; the safe range is one to ten.

The automatic run starts at the selected time in Europe/Berlin. 24 hours means daily, 48 hours means every second day. Daylight-saving changes are handled automatically.
