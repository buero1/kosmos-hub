# Local-Only CRM

- Customer/contact changes and customer notes are saved only in the Hub, including records with historical external IDs.
- CRM and Books API clients, OAuth/callback/webhook routes, import workers, settings sections and sync actions are retired. Email delivery uses the configured Hub mailboxes only; there is no external CRM fallback.
- Startup clears the retired connection credentials and cancels unfinished external import jobs. Historical records, external identifiers, encrypted message bodies, attachments, templates and import history remain in the database. Legacy table/column/catalog names are compatibility identifiers, not active connections.
- Customer patches merge into existing profiles and subforms. Omitted fields and blank sensitive inputs retain their stored values. Invalid dates fail before persistence.
- Date controls use ISO dates; datetime controls display Berlin local time and persist an explicit offset. German legacy dates are recognized. Nonexistent spring DST times are rejected.
- No customer cancellation dates or email messages are created by this release. Any previously failed save must be entered and saved again by the user.

Deployment uses the scoped `--local-crm` guarded release, verifies the exact runtime file set, and retains the previous application directory for rollback. Removed integration tests are replaced by local persistence/retirement regressions; existing mailbox, finance, permissions and rendering tests remain active.
