# Anruffilter

Die Anrufliste bietet neben der Zugriffsansicht einen sofort wirksamen Statusfilter.

- `Überfällige Anrufe` ist die Standardauswahl und zeigt offene Anrufe vor dem aktuellen Zeitpunkt.
- `Geplante Anrufe` zeigt offene Anrufe ab dem aktuellen Zeitpunkt.
- `Offene Anrufe` zeigt überfällige und zukünftige offene Anrufe.
- `Abgeschlossene Anrufe` zeigt erledigte und abgesagte Anrufe.

Beide Auswahlfelder werden gemeinsam übertragen, damit Zugriffsansicht und Statusfilter kombinierbar bleiben.
